# dsh++ v0.1.0

## Introduction

`dsh++` is a lightweight Windows launcher for DeepSeek Harness. It provides a single, responsive entry point for managing DSH services, paths, API settings, system instructions, plugins, and launcher preferences.

## Highlights

- Six-section WinForms interface with a collapsible icon navigation rail.
- Responsive DPI-aware layout with dark, light, and high-contrast themes.
- Automatic discovery of the DSH source tree, Home directory, Profile, plugins, and required tools.
- Low-frequency background checks with tray notifications to reduce CPU and process overhead.
- Safe DeepSeek API connectivity and balance checks with masked local credentials.
- Plugin inventory and enable/disable management with backup protection.
- Launcher self-update from stable GitHub Releases with SHA-256 verification.

## Added

- DSH start, stop, restart, status probe, Git status, update, Web UI, and live log controls.
- Installation and maintenance page with automatic detection and manual path overrides.
- DeepSeek API page for connection testing, model listing, and balance queries.
- System instruction scanner for DSH-scoped `AGENTS.md`, `CLAUDE.md`, settings, and patch files.
- Plugin inventory from Profile manifests, local `file:` dependencies, plugin manifests, and runtime status.
- Launcher settings for theme, font scaling, navigation collapse, refresh intervals, and startup page.
- Self-contained Windows x64 release workflow with executable and SHA-256 checksum assets.

## Changed

- Replaced machine-specific default paths with environment-aware automatic discovery.
- Added privacy-safe defaults for credentials, local settings, logs, sessions, plugins, build output, and release artifacts.
- Kept background monitoring and update checks low-frequency; no automatic DSH restart or billable conversation request is performed.
- Added bilingual README documentation and a release-note driven GitHub Release workflow.

## Fixed

- Improved DPI scaling, font fallback, text clipping, elastic layout, and collapsible navigation behavior.
- Prevented API keys, bearer tokens, local paths, and user-specific runtime details from appearing in logs or release content.
- Added dirty-worktree protection and backup safeguards around DSH updates and plugin configuration changes.
- Added release asset checksum generation for download verification.

## Assets

- `dsh++.exe` — self-contained Windows x64 single-file launcher.
- `dsh++.exe.sha256` — SHA-256 checksum for the launcher asset.

## Requirements

- Windows 10 or Windows 11, x64.
- The self-contained release does not require a separate .NET installation.
- A local DeepSeek Harness environment is required for DSH management features.

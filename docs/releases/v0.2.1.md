# dsh++ v0.2.1

## Introduction

This patch release improves the Windows WinForms launcher experience and keeps the cross-platform release workflow version-aware.

## Highlights

- API credentials now use a stable, responsive layout at the minimum window size.
- System instruction and plugin pages refresh automatically when opened and retain configured paths after settings changes.
- Theme changes no longer report a false save failure caused by premature font disposal.
- GitHub Release checks now handle unexpected runtime errors without an unhandled exception dialog.
- The expanded text navigation is painted without focus artifacts or clipped labels.

## Changed

- macOS bundle metadata now derives its version from the pushed Git tag instead of a hard-coded version.
- Local privacy checks exclude user settings, credentials, design notes, build output, and release output from Git.

## Fixed

- DeepSeek API credential controls being clipped or hidden behind the input field.
- System and plugin inventory views requiring a manual scan after DSH updates or path changes.
- Theme save status incorrectly showing failure after settings were persisted.
- `Parameter is not valid.` errors when checking the dsh++ GitHub Release.
- Navigation button borders and custom-painted content disappearing or showing artifacts.

## Assets

GitHub Actions builds the platform assets and `SHA256SUMS.txt` after the `v0.2.1` tag is pushed.

## Requirements

Release assets are self-contained. DSH itself and the external tools required for DSH service operations remain separate prerequisites.

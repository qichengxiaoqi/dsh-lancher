# dsh++ v0.2.3

## Highlights

- 将 DSH 源码更新改为只读检查：比较本地版本与官方远程版本并提醒。
- 删除 DSH 的自动拉取、切换分支、rebase、依赖安装、构建和重启流程。
- 保留 `upstream` 远程、`dsh++-patches` 本地补丁分支以及补丁状态识别；启动器不会修改该分支。
- dsh++ 自身的 GitHub Release 检查与下载功能保持不变。

## Fixed

- 避免 DSH 工作区修改、插件修改或未跟踪文件触发自动覆盖、备份恢复和重启风险。
- WinForms 与 Avalonia 的 DSH 管理页统一显示“仅检查和提醒”策略。

## Changed

- 需要同步 DSH 时，请在 DSH 仓库外部自行备份并手动处理；dsh++ 不会向 DSH 官方仓库 push。

## Verification

- 核心回归测试覆盖更新提醒为只读且补丁分支状态仍可识别。
- 发布前执行 Release solution build 和 Windows 单文件发布。

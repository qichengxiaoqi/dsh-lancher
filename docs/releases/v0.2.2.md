# dsh++ v0.2.2

## Highlights

- Added an upstream-aware DSH update strategy with `upstream` remote preference and `origin` fallback.
- Added the `dsh++-patches` downstream branch workflow for carrying local DSH fixes without pushing to the official repository.
- Added source-change, protected-file, and unknown-untracked-file classification in the DSH management page.
- Added safe patch rebase with automatic `git rebase --abort` on conflict.
- Added isolated patch storage, update workspace, and `compatibility.json` under `%LOCALAPPDATA%\dsh++`.
- Added launcher settings for the upstream remote and local patch branch.

## Fixed

- Tracked custom service scripts are no longer misclassified as safe-to-pull changes.
- dsh++ Release updates remain independent from DSH source updates.

## Verification

- Core regression tests pass.
- Release solution build completes with zero warnings and zero errors.
- Windows self-contained single-file publish completed for `win-x64`.

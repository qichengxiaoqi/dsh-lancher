# dsh++ v0.2.0

## Introduction

This release keeps the original WinForms launcher for Windows and adds a separate Avalonia UI that reuses `DshPlusPlus.Core` for cross-platform distribution.

## Highlights

- Responsive Obsidian-style shell with collapsible icon navigation.
- One shared Core layer for discovery, API, Git, plugins, system instructions, and settings.
- GitHub Actions builds platform-native self-contained assets and checksums.

## Added

- Avalonia UI project targeting .NET 9.
- Six Avalonia pages: DSH management, maintenance, DeepSeek API, system settings, plugin settings, and launcher settings.
- macOS Intel and Apple Silicon DMG packaging.
- Linux x64 and ARM64 `tar.gz` packaging.
- Windows ARM64 WinForms release asset.

## Changed

- The release workflow now uses Windows, macOS, and Linux runners instead of building every asset on one machine.
- `dsh++.exe` remains the WinForms Windows x64 asset so the existing self-update flow remains compatible.

## Fixed

- Cross-platform builds no longer depend on `net9.0-windows` or WinForms.
- Non-Windows Avalonia builds do not invoke the Windows PowerShell service script.
- Release assets are generated outside the Git worktree and accompanied by SHA-256 checksums.

## Assets

- `dsh++.exe` — WinForms Windows x64
- `dsh++-win-arm64.exe` — WinForms Windows ARM64
- `dsh++-avalonia-win-x64.exe` — Avalonia Windows x64
- `dsh++-mac-x64.dmg` — Avalonia macOS Intel
- `dsh++-mac-arm64.dmg` — Avalonia macOS Apple Silicon
- `dsh++-linux-x64.tar.gz` — Avalonia Linux x64
- `dsh++-linux-arm64.tar.gz` — Avalonia Linux ARM64
- `SHA256SUMS.txt` — checksums for the release assets

## Requirements

All assets are self-contained and include the .NET runtime. DSH itself, Git, and platform-specific tools required for DSH service operations remain external prerequisites. The Avalonia edition is the cross-platform launcher UI; DSH service start/stop remains Windows-specific in this release.

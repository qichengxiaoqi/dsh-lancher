# dsh++ v0.2.6

## Highlights

- Improved Git tool discovery for desktop-launched instances whose `PATH` does not include Git.
- Preserved a valid, previously saved Git executable path when automatic discovery cannot resolve one.
- Kept automatic DSH status refresh lightweight and compatible with the existing local-path detection model.

## Fixed

- Fixed repeated `Git status failed` warnings on the DSH management page when `AutoDetectPaths` replaced a valid saved Git path with the unresolved `git.exe` placeholder.
- Added a regression test covering a valid saved Git path with an empty process `PATH`.

## Changed

- Updated WinForms and Avalonia assembly version to `0.2.6`.

## Assets

- `dsh++.exe` — WinForms Windows x64 launcher.
- `dsh++-win-arm64.exe` — WinForms Windows ARM64 launcher.
- `dsh++-avalonia-win-x64.exe` — Avalonia Windows x64 launcher.
- `dsh++-mac-x64.dmg` and `dsh++-mac-arm64.dmg` — macOS packages.
- `dsh++-linux-x64.tar.gz` and `dsh++-linux-arm64.tar.gz` — Linux packages.
- `SHA256SUMS.txt` — SHA-256 checksums.

## Verification

- Core regression tests passed.
- Release solution build and GitHub Actions release packaging are configured for the `v0.2.6` tag.

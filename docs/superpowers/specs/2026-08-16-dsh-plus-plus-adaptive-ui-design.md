# dsh++ 自适应界面与字体修复设计

## 目标

将 dsh++ 的 WinForms 界面调整为“Adaptive 指挥台”：保留 C 方案的信息层级和青紫 Obsidian 视觉风格，同时采用 B 方案的可收缩图标导航。重点解决中文文字在 DPI 缩放、窄窗口和固定高度控件中的裁切、遮挡与省略问题。

本次只修改启动器项目中的代码，不修改 `<dsh-root>`，不改变已有服务控制、API、插件和性能限制行为。

## 已确认的根因

当前代码中存在以下布局风险：

- `MainForm` 使用绝对导航栏宽度，导航按钮固定宽度/高度，长中文标题没有自适应策略。
- `PageBase`、`MetricCard`、标题栏和按钮使用固定高度，字体实际度量超过高度时会发生裁切。
- 多个页面使用固定按钮宽度、固定表格列宽和不换行的 `FlowLayoutPanel`。
- `ThemeSettings.FontScale` 已存在，但 `ThemeManager` 没有将其应用到控件字体。
- UI 直接混用 `Segoe UI`、`Segoe UI Semibold` 和 `Cascadia Mono`，中文主要依赖系统字体回退，导致不同机器的度量结果不一致。

## 设计方案

### 1. 字体与缩放

新增统一的 UI 度量/字体层，所有页面和自定义控件通过它取得字体、间距和最小高度：

- 中文 UI 首选 `Microsoft YaHei UI`，不可用时回退 `Microsoft YaHei`、`Segoe UI`。
- 日志、路径和哈希等代码内容继续使用 `Cascadia Mono` 或系统等宽字体。
- 统一应用 `ThemeSettings.FontScale`，范围保持 80–140%，并以 DPI 为基础进行二次缩放。
- 通过 `Font.GetHeight(deviceDpi)` 计算控件的安全高度，不再用固定像素高度承载可变字体。
- 标题、正文、辅助文本、按钮、导航和表格分别使用统一字号层级。
- 长文字默认换行；只有路径、哈希和状态摘要等单行字段使用省略号，并提供 Tooltip 或完整预览。

### 2. 自适应导航

- 展开态保留文字导航，默认宽度约 224 DIP。
- 收缩态宽度约 76 DIP，只显示矢量绘制的栏目图标；悬停显示 Tooltip，键盘焦点保留完整可访问名称。
- 品牌区增加收缩/展开按钮，并提供明确的视觉状态。
- 窗口宽度进入窄屏阈值时自动收缩导航；用户仍可手动展开。
- 导航按钮不再把中文标题拼接到固定字符串中，而是由图标、标题和索引独立布局，避免字体回退造成整体裁切。
- 左下角托盘状态芯片在收缩态变为紧凑状态点，展开态显示完整状态文本。

### 3. 自适应内容区

- 页面边距、卡片间距、按钮内边距由统一度量层提供。
- 标题区使用可计算的首选高度；标题与副标题不重叠。
- 卡片标题、指标值和说明文本采用 `AutoSize`/`PreferredSize`，而不是固定高度。
- 操作按钮使用内容驱动宽度和最小宽度，窄屏时允许换行或进入第二行。
- DSH 管理页保留“状态 → 指标 → 操作 → 日志”的层级；空间不足时优先保留状态和核心操作。
- API、维护、系统设置和插件页的表格/输入区使用弹性列；路径、插件来源等长字段提供省略和 Tooltip。
- `DataGridView` 开启合理的行高/文本换行策略，避免列宽固定造成信息消失。
- 主窗口支持 100%、125%、150% DPI；最小窗口尺寸下六栏页面仍可切换且不出现关键控件遮挡。

### 4. 视觉完善

- 保留 Obsidian 深色背景、青色主强调、紫色辅助光晕。
- 导航激活态增加左侧强调线和柔和背景，不使用过多大面积发光。
- 卡片层级通过背景、边框、间距和轻微阴影区分，减少拥挤感。
- 状态芯片统一圆角、颜色语义和内边距。
- 高对比度主题继续可用，并使用同一套布局度量。
- 不引入 WebView2、外部字体下载或持续后台动画，确保低资源占用。

## 组件边界

- `UI/Theme/UiMetrics.cs`：DPI、字体比例、间距、按钮/标题安全高度。
- `UI/Theme/UiFontResolver.cs`：中文 UI 字体和等宽字体回退选择。
- `UI/Controls/NavigationButton.cs`：展开/收缩导航按钮和图标绘制。
- `ThemeManager`：将主题颜色、字体和度量应用到整个控件树。
- `MainForm`：导航收缩状态、窄屏响应和页面壳布局。
- 各页面与通用控件：移除固定高度依赖，改用统一度量和 `PreferredSize`。

## 错误处理与兼容性

- 字体不存在时静默回退，不阻止启动。
- DPI 或字体度量异常时使用安全的最小/最大尺寸边界。
- 用户已有设置中的主题、字体比例和导航宽度继续读取；旧配置缺失新字段时使用默认值。
- 页面数据加载失败只影响页面状态提示，不破坏导航壳或托盘功能。

## 测试与验收

### 自动测试

- 字体回退选择在常见字体缺失时仍返回可用字体。
- 字体比例与 DPI 计算结果在边界值下保持安全范围。
- 导航展开/收缩宽度与窄屏阈值计算正确。
- 旧版设置 JSON 读取后新字段使用默认值。

### GUI 检查

- 100%、125%、150% 显示缩放下启动窗口无标题、按钮和导航文字裁切。
- 1120×720、960×640 及更窄临界尺寸下六个页面可以切换。
- 导航收缩态只显示图标，悬停可见完整栏目名称；展开态文字完整显示。
- DSH 管理、API、系统设置、插件设置中的长路径/长状态可通过省略、换行或 Tooltip 查看。
- 主题切换和字体比例改变后即时生效，托盘和后台低资源行为不回归。

## 性能约束

- 不新增定时扫描、后台动画或高频布局刷新。
- 收缩/展开只更新导航壳和必要的页面宽度，不重新扫描 DSH 文件。
- 字体对象集中创建并在控件销毁时释放，避免反复创建造成 GDI 句柄增长。
